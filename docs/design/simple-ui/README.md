# 쉽고 빠른 화면 — 화면 전체 시안

2026-11-23, 화면 시안 v2, 구현 전

소유자의 말(2026-11-23)에서 시작했어요: 빠르게 정하고 넘기는 덱은 그대로 두고, 왼쪽 패널을 숨길 수 있게 하고, 원리를 설명하는 글을 걷어 내요. 지금 화면을 세 크기(1440×900 · 1194×834 · 390×844)와 두 언어로 찍어 진단하고, 방향 셋을 견준 뒤 A(메뉴 단추 하나)를 그렸어요.

v2(같은 날): 제품의 기본 언어가 영어라서 지금 화면과 시안 화면을 모두 영어로 바꿨어요. 비서의 이름을 토마토(Tomato)로, 위험한 답의 확인을 꾹 누르기로 다시 그렸고, 가운뎃점으로 낱말을 잇지 않는 규칙을 넣었어요. 보드의 설명 글은 한국어예요.

## 파일

| 파일 | 내용 |
|---|---|
| `simple-ui.html` | 시안 보드(한 파일로 묶은 것). 브라우저로 열어요 |
| `board.html` | 보드 원본(그림 파일을 따로 읽어요) |
| `src/board.tpl.html` | 보드의 글 |
| `src/copy.html` | 글 표(문구 열쇠, 지금 글, 제안. 영어 기준) — 보드 11장 |
| `src/refs.html` | 레퍼런스와 확인하지 못한 것 — 보드 14장 |
| `src/screens.py` | 시안 화면 조각(넓은 화면 · 아이폰) |
| `src/simple-kit.css` | 이 시안이 더하는 것(메뉴 단추, 근거 한 줄, 꾹 누르기의 채움, 팝오버). 값은 모두 `tokens.css` 변수예요 |
| `terms.txt` | 화면 그림에 나오면 안 되는 내부 용어. 영어 화면이라 `run`, `receipt` 같은 흔한 낱말은 뺐어요 |
| `harness/shoot.mjs` | 지금 화면을 찍는 스크립트(예시 모드 5180 · 실제 모드 5181) |
| `shots/` | 지금 화면 캡처, 잰 값(`probe-*.json` · `tokens.json`), 진단 핀 자리(`pins.json`) |
| `check/` | 장마다 찍은 그림과 검사 결과 |

## 다시 굽기

```bash
zsh docs/design/simple-ui/build.sh
```

순서: 조립 → 아이콘 → 핀 → 검사 → 한 파일로 묶기. 도구 경로는 `env.sh`에 있어요.

## 지금 화면 다시 찍기

개발 서버 둘을 먼저 띄워요(`pnpm --dir apps/web dev` · `dev:live`, 실제 모드는 로컬 서버가 떠 있어야 해요).

```bash
source docs/design/simple-ui/env.sh && node docs/design/simple-ui/harness/shoot.mjs example
```

`example` 자리에 `out`(로그인 화면)이나 `in`(실제 모드, `shots-simple-en-…@example.test` 영어 계정을 새로 만들어요)을 넣어요. 기본은 영어 화면이고, 이름이 `ko-`로 시작하는 장이 한국어 확인용이에요. 뒤에 장 이름을 쉼표로 적으면 그 장만 찍어요.
