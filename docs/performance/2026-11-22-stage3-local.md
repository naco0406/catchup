에이전트가 답을 기다린 시간은 요청마다 남아요. 실제로 쓰면서 이렇게 재요:

```sql
SELECT percentile_cont(0.5) WITHIN GROUP (ORDER BY answered_at - created_at) FROM catchup.agent_requests WHERE answered_at IS NOT NULL;
```
