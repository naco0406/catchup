# EC2로 옮긴 뒤 잰 것(3.5단계, 2026-11-23)

서울(ap-northeast-2)의 t4g.medium 한 대(ARM · 2 vCPU · 4GB · gp3 30GB 암호화), 주소는 `https://app.catchup.naco.im`. 로컬과 같은 이미지예요(판 `2f34b84`). 잰 곳은 서울의 Mac이에요.

## 값

AWS 가격표(Price List API)에서 읽은 한 달 값이에요. 세금과 전송량, 몇 센트짜리(백업 버킷 · 이미지 저장소)는 빠져 있어요.

| 항목 | 한 달 |
|---|---|
| 인스턴스 t4g.medium(시간당 0.0416달러) | 30.37달러 |
| 디스크 gp3 30GB | 2.74달러 |
| 고정 IP | 3.65달러 |
| 합계 | 36.75달러 |

CPU 크레딧은 표준이라, 다 써도 값이 더 붙지 않고 느려져요.

## 끝 기준

| 기준 | 결과 |

아직 못 본 것: **실제 Codex 로그인과 코딩 세션**(소유자가 이 서버에서 로그인해야 해요), **아이폰 웹 푸시**(홈 화면에 추가한 뒤 실기기에서), 가짜 모델로 하는 코딩 세션 시험(`codex-sessions.mjs`는 로컬 Docker에 붙어서 도는 시험이라 이 서버에 돌리지 않았어요).

## 확인한 것

- 인증서: Let's Encrypt, 앞단(Caddy)이 스스로 받았어요. 2027-02-21까지이고 그전에 스스로 갈아요.
- 밖에 열린 포트: 80 · 443뿐. 22 · 4320 · 5432 · 2019는 닫혀 있어요. 관리는 Systems Manager로 해요.
- 쿠키: Secure · HttpOnly · SameSite=Strict. 다른 출처의 요청은 403, `/health`와 없는 길은 404.
- 비밀값 다섯 개: 서버가 만들어 Parameter Store(SecureString)에 넣었어요. 서버에서는 `/run`(메모리, 0600)에만 있어요.
- 백업: 버킷은 비공개 · 암호화 · 30일 보관. 매일 03:30(한국 시간)쯤 도는 타이머가 켜져 있어요.

## 시험이 걸린 곳(서버의 흠이 아니었어요)

화면 시험을 이 서버에 돌릴 때는 시험의 `ops` · `psql` 한 줄이 Systems Manager를 거쳐서 한 번에 2~3초가 걸려요. 그래서 짧은 시간 창을 재는 시험 셋이 걸렸어요.

- '답하자마자 화면을 닫아도': 시험이 2초 동안 잡는 잠금을 확인하는 명령이 2초보다 늦게 돌아왔어요.
- '알려만 드려요를 읽으면': 되돌리기 토스트가 떠 있는 동안에 DB 확인 두 번이 끝나지 못했어요.
- '약속한 날이 되면'(아이폰): 터치 화면에서 첫 카드를 살짝 밀어 보이는 연출 도중에 넘침 검사가 돌았어요. 검사가 그 연출을 넘침으로 세지 않게 고쳤어요(`e2e/helpers.ts`).

한 줄로(워커 1개) 다시 돌려 모두 통과했어요. 시험 뒤에는 DB를 비우고 소유자 계정만 만들어 뒀어요.
