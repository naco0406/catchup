# 기억 평가 문항 (3.6단계)

기억이 있을 때와 없을 때, 비서가 만든 초안과 추천이 얼마나 맞는지 견주는 문항이에요. 사람이 손으로 단 답이 기준이에요.

- **지금 상태(2026-11-22):** 실제 모델로 돌렸어요(소유자가 허락). 결과와 찾은 문제는 `docs/performance/2026-11-22-memory.md`에 있어요. 7번도 저장소(`octocat/Hello-World`)를 받아서 돌렸어요.
- **돌리는 법:** `node services/api/tests/memory-eval.mjs [--only 3,11]`. 소유자 계정의 ChatGPT 한도를 쓰고(작은 호출 30번쯤), 시작할 때 그 계정의 기억을 모두 '지움'으로 돌려요.
- 규칙으로 확인하는 것(기억이 카드에 붙는지, 지우면 빠지는지, 밖에서 온 글이 선호가 되지 않는지, 일은 눌러야 시작하는지)은 자동 시험에 있어요: `services/api/tests/stage2.rs`, `apps/web/e2e-live/live.spec.ts`.
