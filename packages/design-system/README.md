# @catchup/design-system

CatchUp 디자인 시스템의 정본 파일이에요 — `tokens.css` · `components.css` · `brand/`(로고 · 비서 캐릭터).
설명 · 원칙 · 토큰 표 · 보드는 `docs/design-system/README.md`에 있어요.

- 웹 앱: `import '@catchup/design-system/tokens.css'` · `components.css` · `sprite.svg?raw`
- 로고 · 캐릭터를 바꾸면 `python3 brand/build_brand.py`로 다시 만들어요.
