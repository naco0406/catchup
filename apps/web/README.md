# CatchUp 웹 — 1단계 화면 프로토타입

`docs/design/decision-inbox/plan.md` 1단계예요. 서버 없이 예시 카드로 화면과 손동작을 확인해요. 아무것도 밖으로 보내지 않아요.

## 띄우기

```bash
pnpm install
```

```bash
pnpm dev
```

http://127.0.0.1:5180 에서 열려요. 같은 Wi-Fi의 아이패드 · 아이폰에서 보려면 `pnpm --filter @catchup/web dev --host 0.0.0.0`으로 띄우고 Mac의 IP:5180으로 들어가요.

## 두 가지 모드

| 모드 | 띄우기 | 자료 |
|---|---|---|
| 예시(소개 페이지의 앱) | `pnpm dev` → 5180 | 예시 카드. 서버를 부르지 않아요 |
| 실제 | `pnpm backend:up` · `pnpm dev:live` → 5181 | 로컬 서버(`services/api/README.md`) |

화면 부품은 같고 상태를 대는 쪽(`src/backend.ts`)만 달라요.

## 시험

```bash
pnpm test
```

```bash
pnpm e2e
```

- `pnpm test` — 상태(답 · 10초 대기 · 되돌리기 · 위험한 답 두 번 · 미루기 · 말로 여러 번 답하기 · 처리 기록에서 되돌리기)와 예시 자료 규칙(추천은 맨 위 · 선택지 2~4개 · 두 언어 짝 · 근거 아이콘)을 시험해요.
- `pnpm e2e` — 아이패드 가로(1194×834) · 아이폰(390×844) · 데스크톱(1440×900)에서 1단계 끝 기준을 시험해요. 누르기만으로 7장, 키보드만으로 7장, 10초 되돌리기, 위험한 답, 말로 답하기, 새로 고침, 양쪽 밀기, 두 언어 × 카드 20장의 넘침.

## 구조

| 위치 | 내용 |
|---|---|
| `src/data/cards.{ko,en}.ts` | 예시 카드 20장(같은 id로 두 언어 짝). 앞의 7장이 '월요일 아침', 나머지는 '카드 더 받기' |
| `src/locales/{en,ko}.ts` | 화면 문구. 화면 코드에 글을 박지 않아요 |
| `src/state/store.ts` | 상태 — 순수 함수. 서버가 생기면 같은 동작을 API가 맡아요 |
| `src/components/` | `DecisionCard`(카드 · 선택지 · 미리보기 · 입력창), `useDeck`(밀기: 따라오기 · 문턱 · 스프링 · 나가는 카드), `swipeMath`(밀기 판단 — 따로 시험해요), `Toast`, `Sidebar`, 아이콘 |
| `src/screens/` | 캐치업 덱, 알려만 드려요 덱(`FyiDeck`), 처음, 다 봤어요, 알려만, 미뤄 둔 것, 처리 기록 |
| `src/app.css` | 배치와 반응형만. 색 · 글자 · 모서리는 `@catchup/design-system` 토큰 |

## 손동작

| 무엇 | 어떻게 |
|---|---|
| 답하기 | 선택지 누르기 · 키 1~4 · ↵(추천) |
| 위험한 답 | 두 번 눌러야 정해져요 |
| 비서가 아는 것 | 사이드바 '비서가 아는 것'. 기억을 보고, 고치고, 지우고, 직접 알려 줘요. 같은 사람 · 같은 일의 다음 카드에는 '지난번 · …' 한 줄이 붙어요. 예시 모드에서도 답한 것에서 읽어 내요(`src/state/memory.ts`) |
| 로그인(실제 모드) | 패스키(얼굴 · 지문)가 먼저, 처음이거나 패스키가 없는 기기는 한 번 쓰는 코드로. 패스키는 '연결' 화면에서 등록하고 지워요. https나 localhost에서만 돼요(`http://localhost:5181`) |
| 비서에게 말하기(실제 모드) | 사이드바 '비서에게 말하기', 또는 캐치업 덱 위 막대의 말풍선 단추(`A`)로 덱을 떠나지 않고(보고 있던 카드가 같이 가요). 한 문장을 기억해 · 물어봐 · 일 맡겨 · 카드 찾기 가운데 하나로 받아요. 일과 카드는 눌러야 실행돼요(`src/live/Assistant.tsx`) |
| 알려만 드려요 | 결정이 없는 소식을 한 장씩. 오른쪽 밀기 · 키 → · '읽음' 단추 = 읽음(5초 동안 되돌리기, 처리 기록에 남아요). 왼쪽 밀기 · 키 ← · '나중에' = 읽음으로 치지 않고 맨 뒤로. '카드로'는 결정 카드로 올려요 |
| 되돌리기 | 10초 안에 토스트의 '되돌리기' · 위 막대 ↶ · 키 Z. 토스트는 아이폰에서 입력창 위 한 줄, 넓은 화면에서 위 막대 가운데에 서요(카드를 덮지 않아요) |
| 추천대로 | 터치로 오른쪽 밀기 · 키 → · 아래 오른쪽 단추. 미는 만큼 추천 답 줄이 차오르고, 다 차면 놓아도 돼요. 짧게 튕겨도 돼요(위험한 카드 · 위험한 추천은 안 돼요) |
| 미루기 · 내가 직접 | 키 S · D, 아래 단추(왼쪽이 미루기), 터치로 왼쪽 밀기 · 키 ←. 미룬 뒤 5초 동안 토스트에서 되돌려요(위험한 카드는 조금 따라오다 버텨요) |
| 말로 답하기 | 카드 아래 입력창(아이폰은 화면 아래), 키 / 로 바로 가기. 여러 번 말하면 주고받은 말이 모두 남아요 |
| 처리 기록 | 내가 정한 것 · 미룬 것 · 맡은 것과 비서가 한 것을 시간순으로. 미루기 · 내가 직접도 되돌릴 수 있어요 |
| 서랍 | ≡ 로 열고 Esc 로 닫아요 |
| 언어 | 사이드바 아래 English / 한국어, 또는 주소에 `?lang=ko` |

## 화면 크기

- 1024px 이상: 사이드바 + 카드(아이패드 가로 · 데스크톱)
- 600~1023px: 사이드바는 서랍(아이패드 세로)
- 600px 미만: 아이폰 모양 — 막대 진행, 카드가 화면, 입력창과 단추는 아래에 붙어요
